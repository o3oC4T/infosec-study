# 정보보호개론 · 시험 준비실

정보보호개론의 핵심 개념과 계산을 익히는 학습 사이트입니다. 이해한 내용을 서술형 답안으로 써 보고, 풀이와 채점 기준으로 확인할 수 있습니다.

- 사이트: https://o3oc4t.github.io/infosec-study/ (로그인 없이 접속)
- GitHub: https://github.com/o3oC4T/infosec-study (공개 저장소)

## 학습 구성

- **11개 단원**: 핵심 9개와 보충 2개. 정의, 비교표, 계산 예제, 확인 질문을 제공합니다.
- **62개 서술·계산형 문제**: 모범답안, 세부 채점 기준, 실수하기 쉬운 부분, 관련 개념을 제공합니다.
- **21문항 모의고사**: 핵심 범위를 균형 있게 출제합니다. 빠른 5문항, 단원별 최대 10문항 연습도 가능합니다.
- **계산 연습실**: AES-128 앞 2라운드의 중간 상태, GF(2⁸) 연산, DES S₁ 테이블 읽기.
- **오답 복습**: 최근 자가채점에서 부족한 문항과 북마크를 모아 재시험하고 메모합니다.
- **학습 기록**: 진도·답안·기록·북마크·메모를 브라우저에 저장합니다. JSON 백업·복원이 가능합니다.
- **학습 플랜**: 시험 직전 3시간, 3일 집중, 7일 완성.

모의고사는 기본 60분이며 30분·90분·시간 제한 없음도 선택할 수 있습니다. 모든 문항은 같은 비중으로 자가채점합니다.

## 실행

Node.js 22 이상에서 실행합니다. 사이트 런타임에는 외부 라이브러리나 빌드 과정이 없습니다.

```bash
npm run dev
```

http://127.0.0.1:4173 에 접속합니다. `PORT=8080 npm run dev`로 포트를 바꿀 수 있습니다. ES 모듈을 사용하므로 `index.html`을 파일로 더블클릭하기보다 HTTP 서버를 사용합니다.

`dist/`를 일반 정적 호스팅의 루트로 제공해도 됩니다. 모든 자산은 상대경로이고 화면 이동은 해시 라우팅이므로 하위 경로에서도 실행할 수 있습니다. `.openai/hosting.json`은 현재 Sites 프로젝트의 식별자이며 다른 사이트로 복제할 때 재사용하지 않습니다.

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/check.yml`이 계산·상태·브라우저 테스트를 실행한 뒤 `dist/`를 GitHub Pages로 배포합니다. PR에서는 테스트만 실행합니다. 저장소의 **Actions → Verify and deploy study site**에서 배포 결과를 확인하거나 수동 실행할 수 있습니다.

제출한 시험은 **모의고사 → 나의 시험 기록**에서 다시 볼 수 있습니다. **오답 노트 → 학습 기록 보관하기**에서 백업을 내려받거나 다른 기기의 기록을 가져옵니다.

## 검증

```bash
npm ci
npm run check
npx playwright install --with-deps chromium
npm run test:e2e
```

- AES의 알려진 중간값, 전체 암호화의 Node/OpenSSL 대조, GF 비영 원소의 역원, DES S-box 검증
- 시험 구성 비율·중복 방지, 채점과 최근 오답, 백업 데이터 검증
- 데스크톱과 모바일 브라우저에서 탐색·검색·진도 저장·답안 복구·제출·채점·재시험·시간 종료·백업 복원·계산기 검증

## 저장과 채점

- 서버에 답안을 전송하지 않습니다. 학습 데이터는 `localStorage`의 `infosec-study-v1`에 저장됩니다.
- 제출 기록은 최근 20회 보관합니다. 브라우저·기기·호스팅 주소가 바뀌면 JSON 백업을 가져와야 합니다.
- 타이머는 절대 종료 시각으로 저장되며 다른 화면·탭으로 이동해도 멈추지 않습니다. 탭을 닫은 동안 시간이 끝났으면 다시 열 때 저장된 답안을 제출합니다.
- 제출 전에는 화면에서 해설을 숨깁니다. 정적 학습 도구이므로 감독용 시험이나 정답 은닉 시스템으로 사용하지 않습니다.
- 비어 있는 답안은 0점입니다. 작성한 답안은 기준별 자가채점 전까지 미채점입니다. 모든 문항은 동일 비중이며 문항 내 각 기준도 동일 비중입니다.
- 채점한 최근 답안이 모든 기준을 충족하면 해당 문항은 오답 목록에서 빠집니다. 북마크는 직접 해제할 때까지 유지됩니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `dist/content.js` | 단원, 학습 플랜, 모의고사 구성 |
| `dist/questions.js` | 62문항과 출제·자가채점 계산 |
| `dist/crypto.js` | 교육용 AES·GF·S-box 변환 |
| `dist/store.js` | 학습 상태, 백업 검증, 오답 결정 |
| `dist/app.js` | 화면과 상호작용 |
| `dist/style.css` | 반응형 화면과 인쇄 스타일 |
| `tests/` | 계산·상태·브라우저 검증 |

계산 코드는 학습을 위한 예제입니다. 민감한 데이터를 암호화하는 제품용 라이브러리를 대신하지 않습니다.
